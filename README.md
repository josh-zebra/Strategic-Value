# RFID Value Accelerator

Single-file web app for building RFID value cases. Open `index.html` in a browser; it works offline.

## Publish on GitHub Pages
1. In your Pages repository on github.com, choose **Add file > Upload files**.
2. Drag in `index.html` and `.nojekyll` from this folder, replacing the old `index.html`, and commit.
3. Under **Settings > Pages**, the source should be the branch and folder that hold `index.html`.
4. The site updates in a minute or two at your usual Pages address.

## For sellers
- Start on Setup: customer name, site count and the customer facts (revenue in scope, gross margin, labor rate).
- Case Check lists what to fix before sharing. Exports are marked DRAFT until every check passes.
- Save Session downloads an HTML file with your inputs; open it later to pick up where you left off.
- Nothing you type is sent anywhere. The page runs entirely in your browser.
